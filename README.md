# HDX import

Windows-program för att lägga till saknade ISO-transpondernummer i DelPro, manuellt eller automatiskt.

## Hämta programmet

Hämta senaste installationsfilen och PDF-guiden under [Releases](https://github.com/andepa-tools/HDX-import/releases).

## Funktioner

- Läser djurnummer, officiellt reg-ID och transpondernummer.
- Föreslår nummer för djur som saknar transpondernummer.
- Lämnar befintliga transpondernummer orörda.
- Manuell granskning och daglig automatisk bakgrundskörning.
- Verifierar ändringarna genom återläsning.
- Visar fel och rensar egna körningsloggar äldre än 30 dagar.
- Uppdateringsknapp i huvudprogrammet och installationsprogrammet.

## Stöd i nuvarande version

Svenska SE-ID och landskod 752. Stöd för andra länder ingår inte för närvarande.

## Förutsättningar

Installera på DelPro-datorn. I utrustningsträdet ska **Använd kommandorad ISO** vara ibockad under ISO-processorn. ISO-processorn behöver inte vara aktiv.

HDX import är ett fristående verktyg för import till DelPro. Detta projekt används för installationsfiler, dokumentation och versionsinformation.
